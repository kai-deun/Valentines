# Valentines

A small, multi-page Valentine's experience with animated flowers and a playful "Yes/No" prompt. It is a static HTML/CSS/JS project that runs in any modern browser.

## Pages and flow

1. `index.html` is the intro landing page.
2. `pages/flowers.html` shows the animated flowers and continues the flow.
3. `pages/valentine.html` asks the Valentine question.
4. `pages/yes_page.html` is the celebration page for the "Yes" path.

## Run locally

Open `index.html` in your browser. No build tools or server required.

## Customize

- Update copy in the HTML files under `index.html` and `pages/`.
- Replace or add images in `assets/img/`.
- Tweak animations and styles in `assets/css/`.
- Adjust behavior in `assets/js/script.js` and `assets/js/flowers.js`.

## Project structure

```

```
